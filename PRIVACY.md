# Privacy Policy

**Plugin:** csharp-aesthetic-architecture
**Author:** Chase Redmon
**Last Updated:** March 25, 2026

## Overview

The csharp-aesthetic-architecture plugin is a skill-only plugin for Claude Code. It provides reference material (architecture guidelines, code patterns, review checklists) that Claude reads locally to assist with C# development tasks.

## Data Collection

This plugin **does not collect, store, transmit, or process any user data**. Specifically:

- **No telemetry** — No usage metrics, analytics, or tracking of any kind.
- **No network requests** — The plugin makes no outbound HTTP calls, API requests, or network connections.
- **No data storage** — No files are written outside of the user's existing project. No databases, caches, or logs are created.
- **No personal information** — No names, emails, identifiers, or credentials are collected or accessed.
- **No code exfiltration** — The plugin does not read, copy, or transmit your source code to any external service.

## How It Works

The plugin consists entirely of static Markdown files containing C# coding guidelines. When activated, Claude Code reads these files locally to inform its responses about C# architecture, code quality, and language features. All processing occurs within the Claude Code session on your machine.

## Third-Party Services

This plugin does not integrate with, send data to, or receive data from any third-party services.

## Changes to This Policy

If this privacy policy changes, the update will be reflected in this file with an updated date. Since the plugin collects no data, material changes are unlikely.
